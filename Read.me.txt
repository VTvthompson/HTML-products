Structured Analytic Workflow Framework
Purpose
This framework provides a standardized, tiered workflow for conducting structured intelligence analysis. It reduces cognitive load, accelerates analyst proficiency, minimizes analytic variance, and ensures consistent use of current, authoritative information. The system guides users through a fixed sequence of steps that progress from broad contextual inputs to refined identifiers and final synthesis.

Installation
For optimal performance and ease of use, download this resource directly to your desktop and run it locally in your browser.
Local use ensures faster loading, stable window management, and uninterrupted access to all workflow modules.

How to Use the Framework
1. Begin with Tier 1 (Broad Inputs)
Enter the broadest available descriptor of the subject.
This establishes the shared analytic baseline and populates downstream modules.

Function:

Reduces early ambiguity

Ensures consistent starting conditions

Anchors the workflow

2. Proceed to Tier 2 (Specific Identifiers)
Refine the Tier 1 input using precise identifiers such as model numbers or technical designations.
The system automatically propagates Tier 1 values into Tier 2 modules when appropriate.

Function:

Narrows search scope

Reduces noise

Maintains consistency across mid‑level research steps

3. Complete Tier 3 (Contextual Variables)
Add metadata, vendor information, or contextual attributes that support verification and cross‑checking.

Function:

Supports validation

Prevents assumption drift

Reduces risk of outdated or poisoned data entering the workflow

4. Use Action Buttons to Access Research Steps
Each module includes two actions:

Open in New Tab — Full‑screen research

Open in Split Screen — Opens the resource in a right‑side window for parallel review

Function:

Enforces standardized source order

Reduces procedural variance

Supports reproducible analytic outputs

5. Follow Modules Sequentially
The modules are arranged to reflect the natural progression of analytic reasoning:

Broad understanding

Specific identification

Technical validation

Contextual cross‑checking

Synthesis

Skipping steps reduces analytic reliability.

6. Use the Final Synthesis Step
The final module directs analysts into a visual synthesis environment.
This is where relationships, dependencies, and decision pathways are mapped.

Function:

Converts findings into actionable intelligence

Supports mission planning

Ensures traceability of conclusions

7. Use the Mass‑Close Function
This closes all auxiliary research windows and resets the workflow.

Function:

Prevents browser clutter

Ensures a clean state for the next analysis

Supports high‑tempo operations
